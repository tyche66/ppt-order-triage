# PPT 接单评估 Skill

> 帮助判断 PPT 制作订单是否能由 AI Agent（Codex/OpenCode 等）端到端完成

## 简介

这是一个 OpenCode/Codex Skill，用于在 PPT 接单群中快速评估订单可行性。它读取客服与客户的聊天记录、订单截图、简短需求和已有附件，快速判断在不依赖人工制作或手工修图的前提下，AI Agent 能否完成该订单。

## 核心功能

- **订单类型识别**：自动识别 7 种常见 PPT 订单类型，给出基准可完成率
- **风险修正**：根据需求明确度、资料完整性、工具可用性等加减分项调整
- **硬性拒单条件**：识别必须拒绝或暂停的订单场景
- **工时估算**：给出含质检和返工缓冲的工时区间
- **性价比分析**：计算隐含时薪，帮助判断是否值得接单

## 使用方法

将 `ppt-order-triage/SKILL.md` 放入你的 OpenCode 或 Codex skills 目录：

```
skills/
└── ppt-order-triage/
    └── SKILL.md
```

然后在对话中引用该 skill，提供订单相关信息即可获得评估。

## 输出示例

```markdown
## 接单判断：有条件接
- **AI 可完成率：** 78%（合理区间 70%–85%）
- **判断置信度：** 中
- **订单类型：** 现有 PPT 美化
- **预计总工时：** 3–5 小时（含质检和返工缓冲）
- **性价比：** 报价 ¥X；隐含时薪约 ¥X–¥X / 小时

**为什么能做/不能做：** ...

**主要风险：** ...

**接单前必须确认：** ...

**建议条件：** ...
```

## 适用场景

- PPT 制作接单群
- 自由职业者评估订单可行性
- 团队内部订单分流
